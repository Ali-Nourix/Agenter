# Agenter

**دستیار هوش مصنوعی ابزارمحور، مستقیماً داخل Obsidian.**

Agenter یادداشت‌ها، پژوهش و نوشتن روزمره را در یک محیط هوش مصنوعی کنار هم قرار می‌دهد. می‌توانید با توجه به محتوای Vault گفتگو کنید، وب را جست‌وجو کنید، پرامپت‌های ذخیره‌شده را اجرا کنید و پیش از اعمال تغییرات روی یادداشت‌ها، آن‌ها را بازبینی و تأیید کنید.

## معرفی

Agenter یک افزونهٔ Obsidian است، نه یک سرویس هوش مصنوعی مستقل. شما ارائه‌دهنده و مدل را انتخاب می‌کنید و اطلاعات اتصال خود را وارد می‌کنید؛ در برخی تنظیمات می‌توان از مدل محلی Ollama نیز استفاده کرد. قابلیت‌ها و هزینه‌ها به ارائه‌دهنده و مدل انتخاب‌شده بستگی دارد.

## قابلیت‌ها

- **سه حالت گفتگو:** نوار کناری، پنجرهٔ شناور و پنجرهٔ زمینه‌ای کنار متن انتخاب‌شده.
- **چند ارائه‌دهنده:** OpenAI، Anthropic، Gemini، OpenRouter، Ollama، Cloudflare Workers AI، سرویس‌های سازگار با OpenAI و نشانی‌های سفارشی.
- **زمینهٔ مبتنی بر Vault:** استفاده از یادداشت جاری، پوشهٔ جاری، کل Vault یا بدون زمینهٔ خودکار.
- **ابزارهای یادداشت و وب:** خواندن و جست‌وجوی یادداشت‌ها، بررسی پیوندها و فراداده، فهرست پوشه‌ها، خلاصه‌سازی، جست‌وجوی وب و دریافت نشانی‌ها.
- **تغییرات کنترل‌شده:** ساخت، ویرایش، افزودن متن، جابه‌جایی یا حذف یادداشت تنها مطابق تنظیمات تأیید شما.
- **پشتیبان تغییرات:** پیش از تغییرات، نسخهٔ ایمنی در پوشهٔ `.agenter-backups` ساخته می‌شود؛ حذف نیز از سطل بازیافت Obsidian عبور می‌کند.
- **پرامپت‌های قابل استفادهٔ مجدد:** تعریف فرمان‌های دلخواه در تنظیمات و اجرای آن‌ها از گفتگو.
- **پشتیبانی از فایل‌ها:** تصویر، PDF، فایل‌های Word، PowerPoint، Excel، متن، کد و صوت؛ محدودیت فعلی هر فایل ۳۲ مگابایت است.
- **نمایش راست‌به‌چپ:** پاسخ‌ها و پیش‌نمایش یادداشت‌ها با رندر Markdown خود Obsidian نمایش داده می‌شوند.
- **مدیریت محدودیت مدل:** پایش پنجرهٔ زمینه، فشرده‌سازی گفتگوهای طولانی، تلاش مجدد برای خطاهای موقت و ادامهٔ پاسخ‌های ناقص.

## تصاویر

## نیازمندی‌ها

- Obsidian نسخهٔ **1.7.2** یا جدیدتر.
- نسخهٔ دسکتاپ Obsidian؛ افزونه در حال حاضر فقط برای دسکتاپ تعریف شده است.
- کلید API برای دست‌کم یک ارائه‌دهندهٔ پشتیبانی‌شده، یا نصب محلی Ollama.

## نصب

### نصب دستی

1. از [آخرین انتشار](https://github.com/Ali-Nourix/Agenter/releases/latest) فایل ZIP افزونه یا فایل‌های `main.js`، `manifest.json` و `styles.css` را دریافت کنید.
2. فایل‌ها را در مسیر زیر در Vault قرار دهید:

   ```text
   .obsidian/plugins/agenter/
   ```

3. Obsidian را دوباره بارگذاری کنید.
4. از **Settings → Community plugins** افزونهٔ Agenter را فعال کنید.

## راه‌اندازی

1. به **Settings → Agenter** بروید.
2. یک ارائه‌دهنده اضافه کنید یا تنظیمات موجود را ویرایش کنید.
3. نشانی پایه، کلید API و نام مدل را وارد کنید؛ برای Cloudflare Workers AI می‌توانید از گزینهٔ راه‌اندازی استفاده کنید.
4. با **Test connection & fetch models** اتصال را بررسی کنید.
5. دامنهٔ زمینهٔ پیش‌فرض و مجوز ابزارهایی را که می‌توانند Vault را تغییر دهند، بازبینی کنید.

**نکتهٔ امنیتی:** کلیدهای API در فایل دادهٔ افزونهٔ Obsidian ذخیره می‌شوند. این فایل را منتشر یا به مخزن Git اضافه نکنید.

## حریم خصوصی

- درخواست‌های مدل به ارائه‌دهنده‌ای ارسال می‌شوند که خودتان پیکربندی کرده‌اید.
- ابزارهای شبکه فقط در صورت درخواست گفتگو اجرا می‌شوند.
- ابزارهای تغییردهندهٔ Vault از مرحلهٔ تأیید پیروی می‌کنند و مسیرهای داخلی محافظت‌شده را نمی‌پذیرند.
- سیاست نگهداری داده و هزینه‌ها به ارائه‌دهندهٔ انتخاب‌شده بستگی دارد؛ پیش از استفاده، شرایط آن را بررسی کنید.
